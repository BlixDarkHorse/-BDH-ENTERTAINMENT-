## GitHub Pages

Este repositorio está configurado para usar GitHub Pages desde la carpeta `/docs`. 

Para activar el sitio:
1. Ve a **Settings > Pages** en GitHub
2. Selecciona la rama principal y carpeta `/docs`
3. Configura el DNS de tu dominio según las instrucciones en [docs/README.md](docs/README.md)
